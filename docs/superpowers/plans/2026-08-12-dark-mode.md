# Modo oscuro completo con interruptor — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modo oscuro completo en toda la app de Odent, con interruptor claro/oscuro persistente en `localStorage`, oscuro por defecto, sin tocar datos ni comportamiento.

**Architecture:** El sidebar/topbar ya son oscuros y no cambian. Se agrega un bloque `.dark` en `globals.css` que redefine los tokens de superficie/texto existentes (`--background`, `--color-page`, `--color-muted`, `--color-border`, `--foreground`, `--color-destructive`, `--color-warning`, `--color-warning-bg`); como casi todos los componentes ya consumen esos tokens vía clases Tailwind, un solo cambio de variables retemea la mayoría de la app. Los ~15 archivos que todavía usan grises/blancos crudos de Tailwind (construidos antes del sistema de tokens) se migran a los tokens equivalentes para que también respondan al cambio. Un script inline en `<head>` aplica la clase `dark` antes de la hidratación (evita parpadeo); un botón en `TopBar` alterna la clase y guarda la preferencia.

**Tech Stack:** Next.js 14 App Router, Tailwind CSS 3.4, TypeScript, Vitest + Testing Library.

## Global Constraints

- Ningún cambio de datos, props, queries, ni comportamiento — 100% visual.
- `Sidebar.tsx`, `OdontogramViewTabs.tsx`, `ToothGrid.tsx`, `ToothConditionPanel.tsx` no se tocan (ya usan solo tokens semánticos).
- `TopBar.tsx` y `GlobalSearch.tsx` — sus `bg-white`/`bg-white/70` son intencionales (píldora clara sobre fondo siempre-oscuro) y **no se migran** a `bg-page`.
- Login respeta el mismo oscuro por defecto, sin interruptor propio.
- Preferencia de tema en `localStorage` bajo la clave `odent-theme` (valores `'dark'` | `'light'`), no en la base de datos.
- Paleta oscura exacta (spec `docs/superpowers/specs/2026-08-12-dark-mode-design.md`):
  `--background: #16171C`, `--foreground: #E4E5E9`, `--color-page: #1E2027`,
  `--color-muted: #2A2C34`, `--color-border: #34363F`,
  `--color-destructive: #f87171`, `--color-warning: #F0B429`,
  `--color-warning-bg: #3A2E12`.
- La suite de tests existente (`npm test`) debe seguir pasando sin cambios; baseline conocido: 152 tests pasando, 1 falla preexistente no relacionada en `tests/integration/rls.test.ts`.

- [ ] **Step 4: Crear el componente `ThemeToggle`**

Crear `src/components/layout/ThemeToggle.tsx`:

```tsx
'use client'

import { useEffect, useState } from 'react'

const STORAGE_KEY = 'odent-theme'

export function ThemeToggle() {
  const [isDark, setIsDark] = useState(true)

  useEffect(() => {
    setIsDark(document.documentElement.classList.contains('dark'))
  }, [])

  function toggle() {
    const next = !isDark
    setIsDark(next)
    document.documentElement.classList.toggle('dark', next)
    localStorage.setItem(STORAGE_KEY, next ? 'dark' : 'light')
  }

  return (
    <button
      type="button"
      onClick={toggle}
      aria-label={isDark ? 'Cambiar a modo claro' : 'Cambiar a modo oscuro'}
      className="flex h-9 w-9 items-center justify-center rounded-full bg-white/70 text-foreground/60"
    >
      {isDark ? (
        <svg viewBox="0 0 20 20" fill="none" className="h-4 w-4">
          <circle cx="10" cy="10" r="4" stroke="currentColor" strokeWidth="1.4" />
          <path
            d="M10 2v2M10 16v2M4 4l1.4 1.4M14.6 14.6L16 16M2 10h2M16 10h2M4 16l1.4-1.4M14.6 5.4L16 4"
            stroke="currentColor"
            strokeWidth="1.4"
            strokeLinecap="round"
          />
        </svg>
      ) : (
        <svg viewBox="0 0 20 20" fill="none" className="h-4 w-4">
          <path
            d="M17 12.5A7 7 0 0 1 7.5 3 7 7 0 1 0 17 12.5z"
            stroke="currentColor"
            strokeWidth="1.4"
            strokeLinejoin="round"
          />
        </svg>
      )}
    </button>
  )
}
```

(`bg-white/70` aquí es intencional — el botón vive en el `TopBar`, que
siempre tiene fondo oscuro, igual que los otros botones de ícono junto a
él. No se migra a `bg-page`.)
